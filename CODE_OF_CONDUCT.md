# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In practice

- Review the code and the claim, not the person.
- Assume the other person has context you lack; ask for it.
- No harassment, insults, sexualised language or imagery, or publishing anyone's private information.
- Disagreement about design goes in the pull request or issue, with reasons.

## Scope

Issues, pull requests, discussions, reviews, and anywhere a person represents the project.

## Reporting

Report privately to the maintainers through [GitHub's private reporting](https://github.com/penvhq/penvhq/security/advisories/new) with `Conduct:` at the start of the title. Reports are read only by maintainers. A maintainer involved in the report takes no part in handling it.

## Enforcement

Maintainers may edit or remove comments and contributions, and warn, suspend or ban a participant, following the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
